# Export requirements

## Export

| Req | Requirement | Priority | Type |
|-----|-------------|----------|------|
| EXP-1 | When a run is approved, the exporter shall write a CSV file. | High | Functional |
| EXP-2 | The exporter shall include every unmatched transaction. | Medium | Functional |
| EXP-3 | The export shall finish within one minute for 100k rows. | Medium | Non-functional |
